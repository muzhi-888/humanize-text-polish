# AI 炒股热点复盘

输入股票或板块，AI 复盘近期热点逻辑、资金动向、涨跌归因，帮你建立自己的看盘框架。娱乐学习向，不构成投资建议。

## 它能帮你做什么

- 复盘"为什么涨/跌"：政策、业绩、情绪、资金四维归因
- 梳理板块轮动和催化因素
- 提炼可复用的看盘思路、财报关注项、情绪指标
- 把盘面讲成人话，不堆术语

## 怎么用

1. 输入股票代码、板块或概念
2. 说明你想搞懂哪一段（为什么涨停/为什么跌/资金去哪了）
3. 拿到"逻辑复盘 + 学习点 + 风险提示"

## 适合谁

- 想学看盘但被术语劝退的新手
- 自己做决策、不想被人带节奏的散户
- 复盘交割单、找自己认知盲区的人

## 合规边界

- 不荐股、不预测点位、不承诺收益
- 不引导加群、跟单、代操盘
- 明确标注"娱乐学习用途，不构成投资建议，风险自担"
