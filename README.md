文本去AI味润色器

一个轻量 Skill，把充满 AI 写作痕迹的文本改写得自然、像人说话。

功能
- 去 AI 味：消除夸张象征、宣传语、三段式、破折号滥用等机器特征
- 口语化：把长句拆短、用日常词，保留原意
- 降套话：删掉空泛连接词和无效强调

使用
直接把要润色的文本交给 AI，说明想要哪种风格即可。
